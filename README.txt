VICTORIA FC — FIREBASE CONNECTED

Firebase project: victori4-fc

1. Firebase Authentication: enable Email/Password and create your admin user.
2. Firestore Rules: replace existing rules with firebase_rules.txt and Publish.
3. Open admin.html and sign in with the Firebase Authentication email/password.
4. Upload the entire folder to GitHub.
5. Deploy the GitHub repo on Cloudflare Pages.

The site includes Firestore applications, status lookup, 7-day phone lock, squad, formations, admin reasons/settings, 6A/11A/BOTH, playing position, jersey number/size, previous team and Instagram link.
